A token launch radar: it reads the sealed DefiLlama snapshot, ranks pre-token protocols by an implied value derived from TVL, seven-day growth and age since listing, and gives each one a farming plan. The dashboard is static, no framework and no network.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts --input input/snapshot.json
```
